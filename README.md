# Слепая Зона

Кооперативная стелс-игра для двоих от Sevensave. Агент исследует архивный комплекс, координатор помогает через камеры и пульт. У каждого игрока своя часть информации.

Устанавливайте игру через [Sevensave](https://sevensave.github.io). Поддерживаются Windows x64 и macOS на Intel и Apple Silicon. Для общения нужен внешний голосовой звонок.

Кампания включает шесть операций. Успешные проверки сохраняют общие контрольные точки; продолжить из сохранения может любой участник, создав новую комнату и пригласив напарника.

В этом репозитории размещаются готовые сборки игры. Лицензии сторонних компонентов включены в приложение.
